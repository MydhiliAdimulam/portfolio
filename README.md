# Mydhili Adimulam — Portfolio

A responsive personal portfolio website built as a static page. It highlights the projects in Mydhili's GitHub profile, with direct links to each project, and includes contact links.

## Featured projects

- [Online Auction System](https://github.com/MydhiliAdimulam/ONLINE-AUCTION) — web-based auction application built with PHP and SQL.
- [Song Recognition Based on Audio Fingerprinting](https://github.com/MydhiliAdimulam/SONG-RECOGNITION-BASED-ON-AUDIO-FINGER-PRINTING) — song recognition project using audio fingerprinting, with a Python app and notebook workflow.

## Run locally

Open `index.html` in a browser. No build step or dependencies are required. Google Fonts are loaded over the network; system sans-serif fonts are used if unavailable.
